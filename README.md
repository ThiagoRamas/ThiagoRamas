## Proyectos destacados

### [PlayerHub](https://github.com/ThiagoRamas/playerhub)

Plataforma web en español para explorar clubes, planteles y trayectorias de futbolistas.

- Aplicación publicada con frontend, API REST y base PostgreSQL propia.
- Proceso ETL con normalización, deduplicación, trazabilidad y cargas incrementales.
- Cobertura de 81 clubes argentinos y más de 1.000 jugadores.
- Pruebas automatizadas para importación, API y frontend.
- Tecnologías utilizadas: Python, FastAPI, PostgreSQL, React y Docker.

**[Abrir la aplicación](https://playerhub-thiagoramas.tramascai.chatgpt.site)** · **[Explorar la API](https://playerhub-oac3.onrender.com/docs)**

### [RojoStats](https://github.com/ThiagoRamas/RojoStats)

Monitor automatizado de estadísticas públicas del canal de YouTube de Club Atlético Independiente.

- Consulta de métricas mediante la API oficial de YouTube.
- Historial de crecimiento, tendencias y rendimiento de videos.
- Informe actualizado en Telegram sin generar mensajes duplicados.
- Ejecución automática cada hora mediante GitHub Actions.
- Pruebas para cálculos, historial, tendencias y manejo de errores.
